🎯 The goal of this course

To learn, not just copy snippets. By the end you should be able to configure EF Core correctly for any environment, explain what EF Core does and what SQL it generates, diagnose slow data access with real measurements, and fix it with the right technique.

Every lesson starts with its own goal and why it matters, and ends with an exercise and a quiz so you can check your understanding.

Prerequisites C# and basic SQL (SELECT, JOIN, WHERE). Install the .NET 10 SDK and a database: SQL Server Developer/Express, LocalDB, Docker (mcr.microsoft.com/mssql/server), or PostgreSQL. Lesson 1 sets up the playground project.
How to get the most out of this course
  1. Keep SQL logging on (Lesson 2) for the whole course. Seeing the SQL is the real lesson.
  2. Do the exercises against a database with realistic volumes (100k+ rows), not 10 rows.
  3. Measure before and after every optimization. Lesson 25 shows how to do it properly.
  4. Stuck? Select the confusing sentence, right-click it and ask the AI tutor, then verify the answer against the cited docs.

Content is based on the official EF Core performance documentation, the EF Core 7–10 release notes, and established community practice. APIs evolve, so check each release's What's new page.
